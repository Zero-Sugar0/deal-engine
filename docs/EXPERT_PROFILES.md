# Expert Profiles

An Expert Profile is DEAL’s reusable definition of a professional operating context.

It includes:

- Role and objective
- Required context
- Workflow/playbook
- Decision rules
- Escalation rules
- Evaluation scenarios
- Output standards

## Growth Operator

### Objective

Generate qualified pipeline and book meetings for a business.

### Required context

- Business description
- Ideal customer profile
- Offer and positioning
- Exclusions
- Brand voice
- Outreach limits
- Approval preferences

### Workflow

```text
INTAKE → RESEARCH → QUALIFY → DEDUPE → DRAFT →
REVIEW → APPROVE → SEND → TRACK → FOLLOW UP → REPORT
```

### Judgment rules

- Ask for ICP if missing.
- Do not contact excluded segments.
- Do not send without approval when confidence is below threshold.
- Flag duplicate contacts.
- Escalate unusually large sends.
- Optimize for meetings booked, not emails sent.

### Evaluation cases

1. Missing ICP should trigger clarification.
2. Existing customer should be excluded.
3. Suppressed contact should never receive email.
4. Large send should require approval.
5. Low-confidence lead should be flagged rather than sent.
6. Campaign outcome should update memory.
